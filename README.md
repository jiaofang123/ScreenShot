# ScreenShot

一个本地优先的 Windows / macOS 桌面截图与录屏工具，支持快速框选、手动滚动长截图、文字标注、自动复制和多来源录屏。

## 当前能力

- 全局快捷键：`Ctrl/Cmd + Shift + X`
- 任意桌面内容的矩形框选
- 框选后可拖动四角调整范围，拖动选框外的区域可重新框选
- 普通截图与手动滚动长截图
- 框选后“完成并复制”直接复制截图，“编辑截图”进入标注界面
- 箭头、矩形、画笔、文字和马赛克
- 文字标注支持中文、多行、颜色和字号调整，以及撤销/重做
- 预览图鼠标滚轮缩放、指针中心缩放和拖拽平移
- 完成后用系统原生剪贴板复制 PNG，也可以另存为文件
- 编辑器快捷键：`Ctrl/Cmd + Enter` 完成并复制，`Ctrl/Cmd + S` 另存为
- 系统托盘常驻
- 录屏支持应用窗口、浏览器页签、电脑桌面和框选区域；可暂停、继续、停止并保存
- 15 / 30 / 60 fps、最高 1080p / 4K、可选共享声音；优先输出 MP4，兼容 WebM

## 录屏

1. 在主窗口切换到 **录屏**，选择 **应用窗口**、**浏览器页签**、**电脑桌面** 或 **框选区域**。
2. 选择浏览器、帧率、画质和是否录制共享声音，点击 **开始录屏**，选择视频保存位置。
3. 工具会打开本机 Chrome / Edge 的录屏页面。点击页面中的选择按钮，在浏览器共享面板中授权要录制的具体窗口、页签或屏幕。浏览器页签必须在所选浏览器中打开；应用模式录制一个具体窗口，桌面模式录制一块屏幕。
4. **框选区域**模式先选择屏幕，再在实时预览上拖动框选范围，四角可再次调整，点击 **开始录制选区**。其他模式在共享后自动进入 3 秒倒计时，可切回目标应用。
5. 使用录屏页面、工具中的按钮或托盘菜单 **停止录屏并保存** 结束录制；可暂停后继续。停止快捷键为 `Ctrl/Cmd + Alt + Shift + R`，注册成功时界面会显示提示。等待“已保存”后可打开所在文件夹。

录屏使用浏览器原生 `getDisplayMedia` 共享选择器，需要新版 Chrome / Edge；Tauri 内置 webview 不承担页签采集。macOS 首次使用时需允许 **Chrome / Edge** 录制屏幕，浏览器每次共享仍需用户选择授权。共享声音是否可用取决于浏览器、系统及来源，不采集麦克风；未提供声音时会提示并仅录制画面。

视频在浏览器编码后分片写入本机文件，仅通过 `127.0.0.1` 连接 ScreenShot，不上传到外部服务，也不把整段视频积存在内存。区域录制使用后台视频帧处理，不依赖前台预览刷新。请保留录屏页面直到保存完成；意外关闭时尽量保留已接收的数据，文件名带“未完成”，可能无法完整播放。正常退出工具会先停止并保存录屏。

默认优先 MP4；选择 `.webm` 路径时优先 WebM。浏览器不支持所选编码时会使用可用格式并调整扩展名，实际路径显示在完成状态中。录制结束前使用临时文件，成功保存后再替换用户选择的目标文件；格式切换不会覆盖另一个已存在的文件。

## 添加文字

1. 框选后选择 **编辑截图**，在左侧工具栏选择 **文字**，点击截图中的位置。
2. 输入文字，按 `Enter` 换行；使用颜色选择器和字号滑块调整样式（12–96px）。
3. 点击 **添加文字** 确认，或按 `Esc` / 点击 **取消** 放弃当前输入。点击截图其他位置可继续添加，切换工具会确认当前文字。
4. 点击 **完成并复制** 或 **另存为**，文字会随截图一起导出；仍在输入中的文字也会自动确认。

输入框中的空格、换行和 `Ctrl/Cmd + Z` 保留正常的文字编辑行为。确认后的文字可与其他标注一起撤销/重做；文字超出截图边缘的部分会被裁切。

## 直接完成截图

1. 按 `Ctrl/Cmd + Shift + X` 冻结屏幕，拖动鼠标框选区域。需要微调时，拖动选框四角的小方块；拖动选框外的区域可重新框选。
2. 点击 **完成并复制**，或在未聚焦工具条按钮时按 `Enter`，直接复制选区原始像素并收起冻结窗口，可回到原来的应用粘贴。
3. 需要添加文字、箭头、马赛克等标注时，点击 **编辑截图**；需要拼接长图时，选择 **滚动长截图**。

直接复制不打开编辑器，也不执行用于编辑器预览的 PNG 编码。如果剪贴板写入失败，冻结窗口保留选区并显示错误，可重试复制或改为编辑截图。复制过程中会禁用重复提交和取消操作，避免重复写入。

调整角点时，对面的角保持固定，支持缩小、放大及越过对角点反向调整；范围限制在当前屏幕内。尺寸提示会实时更新，复制、编辑和滚动长截图均使用调整后的范围。

## 响应速度

- 启动时预先创建隐藏的框选窗口，后续截图复用窗口；取消或完成时清空画面和框选状态。
- Rust 缓存当前截图的原始像素。复制和保存只传递截图编号及标注，直接在后台合成并输出，避免整张图片反复进行 Base64 传输和 PNG 编解码。
- PNG 使用快速无损编码，导出的原始像素和透明度不变。减少冻结前的固定等待，在图片加载后立即显示覆盖层。
- 安装使用 Release 构建。Debug 构建的图像处理明显更慢，适合开发调试。

本机 2560×1440 合成图的单次处理基准：预览由旧 Debug 版约 1551ms 降至 Release 版约 98ms；截图 PNG 由约 2757ms 降至约 56ms。新复制路径不再进行整图 PNG 往返，带矩形标注的合成约 3ms。这些数值不包含屏幕捕获、窗口显示和系统剪贴板耗时，完整操作耗时取决于显示器及系统环境。

复现图像处理基准（不访问屏幕或剪贴板）：

```sh
cd src-tauri
cargo run --release --example latency
```

## 开发

```powershell
npm install
npm run tauri dev
```

只检查前端：

```powershell
npm run build
```

检查 Rust：

```powershell
cd src-tauri
cargo test
cargo check
```

录屏集成测试使用生成的画面和音频流，实际执行浏览器编码、区域裁剪、后台控制、分片保存、MP4 / WebM 解码和中断恢复，不访问桌面或麦克风。先安装 Playwright 及 Chromium，再运行：

```sh
cd src-tauri
cargo build --locked --example recording_harness
cd ..
npm install --no-save --package-lock=false playwright
npx playwright install chromium
node tests/recording.integration.mjs
```

已有 Playwright 时可用 `PLAYWRIGHT_MODULE` 指定模块路径，用 `RECORDING_CHROME_PATH` 指定 Chrome 可执行文件。自动化不替代系统共享选择器、屏幕权限和 Windows 实机验证。

## Windows 打包

```powershell
npm run tauri build -- --bundles nsis
```

生成产物：

- `src-tauri\target\release\screenshot-desktop.exe`
- `src-tauri\target\release\bundle\nsis\ScreenShot_0.1.0_x64-setup.exe`

说明：当前工程路径包含中文和 WPS 云盘目录，WiX MSI 打包可能报 `LGHT0001 / 0x8007007B`；NSIS 安装包已验证可生成。

## macOS 打包

```sh
npm run tauri build -- --bundles app
```

生成 `src-tauri/target/release/bundle/macos/ScreenShot.app`。复制到 `/Applications` 后启动；首次使用需授予屏幕录制权限。
