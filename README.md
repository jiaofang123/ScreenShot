# ScreenShot

一个桌面截图、录屏与演示视频制作工具，支持快速框选、手动滚动长截图、文字标注、录屏、中文旁白和音视频合成。视频制作整合自 [Video-Narration-Studio](https://github.com/jiaofang123/Video-Narration-Studio)。

## 当前能力

- 全局快捷键：`Ctrl/Cmd + Shift + X`
- 任意桌面内容的矩形框选
- 框选后可拖动四角调整范围，拖动选框外的区域可重新框选
- 普通截图与手动滚动长截图
- 框选后“完成并复制”直接复制截图，“编辑截图”进入标注界面
- 箭头、矩形、画笔、文字和马赛克
- 文字标注支持中文、多行、颜色和字号调整，以及撤销/重做
- 预览图鼠标滚轮缩放、指针中心缩放和拖拽平移
- 完成后用系统原生剪贴板复制 PNG，也可以另存为文件
- 编辑器快捷键：`Ctrl/Cmd + Enter` 完成并复制，`Ctrl/Cmd + S` 另存为
- 系统托盘常驻
- 录屏支持应用窗口、浏览器页签、电脑桌面和框选区域；可暂停、继续、停止并保存
- 15 / 30 / 60 fps、最高 1080p / 4K、可选共享声音；优先输出 MP4，兼容 WebM
- 视频制作：分时段文字稿、中文旁白生成与试听、文字叠加、音视频合成、排序合并和项目保存恢复
- 重新生成语音、合成视频按原 Narration Studio 逻辑覆盖旧结果

## 录屏

1. 在主窗口切换到 **录屏**，选择 **应用窗口**、**浏览器页签**、**电脑桌面** 或 **框选区域**。
2. macOS 的应用、桌面和区域使用原生录屏：在当前工具内选择具体目标、帧率、画质、系统声音、麦克风、指针和点击效果。区域模式点击 **框选录制区域**，工具先隐藏，再在所选显示器的桌面上全屏框选，四角可调整；按 Enter 或 **确认录制区域** 返回设置，Esc 取消。**重新框选** 时取消会保留上次确认的范围。开始后倒计时 3 秒并收起窗口，自动保存，无需选择文件位置。
3. **浏览器页签**保留 Chrome / Edge 的独立页签授权方式，需在所选浏览器中打开目标页签。其他系统使用浏览器兼容录制入口。
4. 单独录屏可勾选 **录完直接进入视频制作**，保存后自动导入；也可在完成后点击 **添加旁白 / 编辑视频**。视频制作中的 **录屏** 直接打开浏览器设置页，在那里选择方式、目标和参数；保留视频制作页面及全屏状态，保存后自动回填当前项目，支持控制页连续录制。
5. 使用工具按钮或托盘菜单 **停止录屏并保存** 结束录制；可暂停后继续。停止快捷键为 `Ctrl/Cmd + Alt + Shift + R`。等待“已保存”后可打开所在文件夹。
6. Chrome / Edge 录屏控制页保存后提供 **继续新录制**，可直接切换标签页、窗口、区域或屏幕，调整帧率、画质和共享声音；每段使用独立文件名。项目录屏继续保存在项目素材目录，独立录屏按每段开始时的本机日期归档。页面保留期间不会在保存 30 秒后失效，完成后刷新也可继续。
7. macOS 控制页的窗口、桌面和区域使用原生采集，排除 ScreenShot 主窗口、截图覆盖层和浏览器录屏控制窗口；工具及控制页也不能作为窗口目标。标签页录制排除当前控制页，并检查其他控制页的 Capture Handle。普通 Chrome 内容窗口仍可选择，区域框选确认后返回控制页。
8. 画质支持最高 **1080p / 2K（2560×1440）/ 4K**，原生及浏览器录制均生效，保持来源比例且不放大低分辨率内容。16:10 屏幕选择 2K 时最高输出 2304×1440。
9. 已完成录制或设置页尚未开始录制时，从工具再次发起同一浏览器的录屏会复用现有控制窗口；新任务仍使用独立会话和文件，切换项目会更新保存位置。页面启动期间防止重复打开，结束使用的旧控制页自动关闭。关闭设置页、取消选区或设置页初始化失败会释放未开始的任务；实际录制、暂停和保存期间会阻止替换，保留当前视频。点击菜单栏 / 托盘 ScreenShot 图标可打开菜单，选择 **显示主窗口** 或 **停止录屏并保存**。macOS 从顶部共享菜单停止后，也可点击程序坞 ScreenShot 图标重新显示、恢复并聚焦工具主窗口。

Mac 原生录屏使用 ScreenCaptureKit / AVFoundation，需要 macOS 13+，首次允许 **ScreenShot** 录制屏幕。麦克风和点击效果需 macOS 15+，麦克风单独授权；系统声音与麦克风同时启用时会在保存阶段混合音轨。页签兼容录制使用新版 Chrome / Edge 的 `getDisplayMedia`，需要给所用浏览器授予屏幕录制权限，每次共享仍需用户选择授权；共享声音是否可用取决于浏览器、系统及来源。真实单页签采集与录制浏览器窗口是不同来源。

原生录屏直接写入本机临时 MP4，完成后提交到目标路径；截图工具自身的窗口会从桌面录制中排除。浏览器兼容录制分片写入本机文件，仅通过 `127.0.0.1` 连接 ScreenShot，不把整段视频积存在内存；页面需保留到保存完成。异常尽量保留带“未完成”的视频文件。正常退出工具会先停止录屏并保存。

原生录屏输出 MP4。浏览器兼容录制默认优先 MP4，编码不可用时兼容 WebM 并调整实际扩展名。实际路径显示在完成状态中。

默认工作目录为用户主目录下的 `screenshot`，本机是 `/Users/xylink/screenshot`：

- 独立录屏：`screenshot/YYYY-MM-DD/视频.mp4`，日期目录自动创建。
- 视频项目：`screenshot/projects/合成视频-YYYY年MM月DD日HH时mm分ss秒/`，保留 Narration Studio 的命名、重名编号及 `assets、voices、renders、exports、tmp、project.json` 结构。项目录屏直接保存到 `assets`，回填时登记原文件，不再复制一份。
- 已打开的项目继续使用其原位置，也可通过“新建项目”选择其他文件夹；原项目的恢复及重新生成覆盖逻辑保持不变。

## 视频制作与窗口布局

主窗口提供 **截图 / 录屏 / 视频制作**。截图与录屏保持紧凑窗口（初始 960 × 720）；首次进入视频制作最大化到可用桌面，也可手动切换系统全屏。两个工作区分别记忆尺寸、位置及最大化状态，切回时恢复；项目和编辑状态随工作区切换保留。

视频制作右上方的 **收起顶部**可隐藏顶部说明、项目操作和步骤引导，扩大素材及视频编辑区；上方仍保留模式切换、全屏按钮和 **展开顶部**。折叠偏好会记住，切换工作区或重新启动后继续沿用；折叠不会重新加载编辑器。

**音视频合并列表**标题上方的分割线可上下拖动，调整列表和预览的高度；双击恢复默认，聚焦分割线后也可用上下方向键调整。高度偏好保存在本机，窗口或顶部布局变化时自动限制范围，避免挤掉预览。

本机录屏设置的 **更多设置：鼠标与点击效果**提供“显示鼠标指针”和“显示点击效果”，两项默认开启；工具内录屏页采用相同默认值。录制窗口、屏幕或区域时按所选设置传给原生组件，连续录制可修改；浏览器页签不显示这些原生选项。点击效果需要 macOS 15 或以上版本。

1. 点击 **视频制作**，录屏或导入已有视频；支持打开原 Narration Studio 保存的项目文件夹。点击 **录屏** 直接打开 Chrome / Edge 设置页，无需切换到工具的录屏页签，也不弹录屏保存对话框。
2. 给视频添加一个或多个时间范围，输入中文文字稿，选择语速，生成旁白并试听。
3. 默认 **Edge 中文女声（联网）**：文字稿会发送到在线语音服务。可切换 **本机语音（离线）**；Mac 使用 Tingting，Windows 使用系统语音。视频文件在本机处理。
4. 可插入文字、调整样式。点击左侧文字详情卡片，在右侧带箭头的浮层中编辑 **文字内容**、**从第几秒出现** 和 **显示几秒**，点击外部或按 Esc 收起；结束时间自动计算，不能超出视频范围。预览与合成导出使用同一时间范围。
5. 重新生成语音和重新合成均覆盖同一旧结果；不会增加额外历史版本。勾选需要合并的成片，拖动卡片或手柄调整顺序后合并预览、导出；列表中的固定编号用于核对视频，拖拽、取消勾选及重新打开项目均不变。
6. 修改会自动保存，顶部显示保存状态。**保存项目**（⌘/Ctrl+S）立即保存当前项目；**更多 → 项目另存为**可将素材、文字稿、语音、合成视频及成片打包到其他文件夹。移动文件夹后可通过 **打开项目**继续编辑。**合并导出**生成可分享的最终视频，与保存项目不同。

顶部步骤条会根据当前内容提示下一步：添加视频、填写旁白、生成语音、合成、预览和导出。修改原稿后提示更新语音及合成结果；删除最后一段语音或文字后，也可更新合成恢复原画面。生成仍覆盖原文件及编号。点 **编辑原视频** 回到源素材；处理结果可直接 **打开文件位置**。主工具的 **使用帮助**提供截图、录屏及视频制作的操作说明。录屏默认保留常用设置，麦克风及鼠标选项收在“更多设置”，开始倒计时可取消。

合并会将不同尺寸素材按比例放入同一 1920×1080 画布，保留原比例并按需留边；文字在等比例画面上绘制，避免拉伸。旁白比画面长时保留末帧，末尾新增文字在合并预览和导出中都会显示。覆盖生成后刷新视频和语音缓存，避免继续播放旧结果。

截图、录制与视频合成在本机执行；在线语音需要联网。打包包含媒体运行时，因此安装体积会增加；媒体进程在使用视频功能时才启动。来源及依赖说明见 [THIRD_PARTY.md](./THIRD_PARTY.md)。

素材列表也支持拖动卡片或手柄排序，保存和重新打开项目后保持显示顺序。两种列表均提供插入位置提示、边缘自动滚动，按 Esc 取消拖拽；聚焦手柄后可用上下方向键排序。素材排序不会改动已安排的合并顺序。

文字稿卡片右上角的 **×** 可删除该段及对应语音。正在试听的对应语音会停止，项目内生成的音频、文字与中间文件同步清理；其他卡片仍引用的语音及项目外文件会保留。已合成的视频保留，需要更新旁白时可重新合成。删除最后一张卡片后列表保持为空，可点击 **添加** 新建。

## 添加文字

1. 框选后选择 **编辑截图**，在左侧工具栏选择 **文字**，点击截图中的位置。
2. 输入文字，按 `Enter` 换行；使用颜色选择器和字号滑块调整样式（12–96px）。
3. 点击 **添加文字** 确认，或按 `Esc` / 点击 **取消** 放弃当前输入。点击截图其他位置可继续添加，切换工具会确认当前文字。
4. 点击 **完成并复制** 或 **另存为**，文字会随截图一起导出；仍在输入中的文字也会自动确认。

输入框中的空格、换行和 `Ctrl/Cmd + Z` 保留正常的文字编辑行为。确认后的文字可与其他标注一起撤销/重做；文字超出截图边缘的部分会被裁切。

## 直接完成截图

1. 按 `Ctrl/Cmd + Shift + X` 冻结屏幕，拖动鼠标框选区域。需要微调时，拖动选框四角的小方块；拖动选框外的区域可重新框选。
2. 点击 **完成并复制**，或在未聚焦工具条按钮时按 `Enter`，直接复制选区原始像素并收起冻结窗口，可回到原来的应用粘贴。
3. 需要添加文字、箭头、马赛克等标注时，点击 **编辑截图**；需要拼接长图时，选择 **滚动长截图**。

直接复制不打开编辑器，也不执行用于编辑器预览的 PNG 编码。如果剪贴板写入失败，冻结窗口保留选区并显示错误，可重试复制或改为编辑截图。复制过程中会禁用重复提交和取消操作，避免重复写入。

调整角点时，对面的角保持固定，支持缩小、放大及越过对角点反向调整；范围限制在当前屏幕内。尺寸提示会实时更新，复制、编辑和滚动长截图均使用调整后的范围。

## 响应速度

- 启动时预先创建隐藏的框选窗口，后续截图复用窗口；取消或完成时清空画面和框选状态。
- Rust 缓存当前截图的原始像素。复制和保存只传递截图编号及标注，直接在后台合成并输出，避免整张图片反复进行 Base64 传输和 PNG 编解码。
- PNG 使用快速无损编码，导出的原始像素和透明度不变。减少冻结前的固定等待，在图片加载后立即显示覆盖层。
- 安装使用 Release 构建。Debug 构建的图像处理明显更慢，适合开发调试。

本机 2560×1440 合成图的单次处理基准：预览由旧 Debug 版约 1551ms 降至 Release 版约 98ms；截图 PNG 由约 2757ms 降至约 56ms。新复制路径不再进行整图 PNG 往返，带矩形标注的合成约 3ms。这些数值不包含屏幕捕获、窗口显示和系统剪贴板耗时，完整操作耗时取决于显示器及系统环境。

复现图像处理基准（不访问屏幕或剪贴板）：

```sh
cd src-tauri
cargo run --release --example latency
```

## 开发

```powershell
npm install
npm run media:install
npm run media:prepare
npm run tauri dev
```

只检查前端：

```powershell
npm run build
```

检查 Rust：

```powershell
cd src-tauri
cargo test
cargo check
```

录屏集成测试使用生成的画面和音频流，实际执行浏览器编码、区域裁剪、后台控制、分片保存、MP4 / WebM 解码和中断恢复，不访问桌面或麦克风。先安装 Playwright 及 Chromium，再运行：

```sh
cd src-tauri
cargo build --locked --example recording_harness
cd ..
npm install --no-save --package-lock=false playwright
npx playwright install chromium
node tests/recording.integration.mjs
node tests/recording-lifecycle.integration.mjs
```

已有 Playwright 时可用 `PLAYWRIGHT_MODULE` 指定模块路径，用 `RECORDING_CHROME_PATH` 指定 Chrome 可执行文件。自动化不替代系统共享选择器、屏幕权限和 Windows 实机验证。

生命周期回归使用真实本机连接和浏览器编码，检查空闲设置页的 CPU 占用、同窗口替换、关闭 / 取消 / 初始化失败后的任务释放、录制期间拒绝替换、重复打开控制页不会停止原录制，以及保存视频完整解码。

视频制作集成测试使用生成的视频和本机语音，验证生成覆盖、文字合成、合并和项目迁移：

```sh
node tests/studio.integration.mjs
# 文字稿删除的真实文件清理、共用文件保护及项目结构恢复
node tests/studio-editing.integration.mjs
# 启动 Vite 后，使用已安装的 Playwright 验证同窗口工作区和录屏回填
node tests/studio.ui.mjs
# 实际鼠标排序、固定编号、语音删除、文字时间设置及真实媒体导出
node tests/studio-editing.ui.mjs
# 不同比例素材合并：真实 FFmpeg 编码、字体/方块比例及预览/导出完整解码
node tests/studio-aspect.integration.mjs
# 桌面框选与录制范围回填，及旧录制结果不会误导入的回归（模拟 Tauri IPC）
node tests/recording-region.ui.mjs
node tests/recording-session.ui.mjs
node tests/recorder-controller.ui.mjs
```

macOS 上可在启动 Vite 后运行真实 WKWebView 编辑验收（独立测试窗口、数据目录和生成素材，使用生产 IPC）：

```sh
cd src-tauri
cargo build --locked --example studio_webview_harness
cd ..
node tests/studio-webview.integration.mjs
```

此测试复现嵌入式 WebView 的原生确认框不可用，验证页面内删除确认、取消、语音文件清理，以及文字详情编辑的实际保存。

macOS 原生编码器提供不访问屏幕/麦克风的自检：

```sh
src-tauri/resources/runtime/screenshot-recorder self-test /tmp/native-recorder-test.mp4
```

以上测试覆盖合成媒体、模拟窗口 IPC 和真实编码器；实际屏幕采集另用下面的真机验收，系统首次权限和 Windows 仍需人工确认。

macOS 真机录屏验收（会打开独立 Chrome 测试窗口，并实际录制该窗口、屏幕和区域；请先授权屏幕录制）：

```sh
cd src-tauri
cargo build --locked --example native_recording_harness
cd ..
```
