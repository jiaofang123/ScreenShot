# ScreenShot

一个桌面截图、录屏与演示视频制作工具，支持快速框选、手动滚动长截图、文字标注、录屏、中文旁白和音视频合成。视频制作整合自 [Video-Narration-Studio](https://github.com/jiaofang123/Video-Narration-Studio)。

## 当前能力

- 全局快捷键：`Ctrl/Cmd + Shift + X`
- 任意桌面内容的矩形框选
- 框选后可拖动四角调整范围，拖动选框外的区域可重新框选
- 普通截图与手动滚动长截图
- 框选后“完成并复制”直接复制截图，“编辑截图”进入标注界面
- 箭头、矩形、画笔、文字和马赛克
- 文字标注支持中文、多行、颜色和字号调整，以及撤销/重做
- 预览图鼠标滚轮缩放、指针中心缩放和拖拽平移
- 完成后用系统原生剪贴板复制 PNG，也可以另存为文件
- 编辑器快捷键：`Ctrl/Cmd + Enter` 完成并复制，`Ctrl/Cmd + S` 另存为
- 系统托盘常驻
- 录屏支持应用窗口、浏览器页签、电脑桌面和框选区域；可暂停、继续、停止并保存
- 15 / 30 / 60 fps、最高 1080p / 4K、可选共享声音；优先输出 MP4，兼容 WebM
- 视频制作：分时段文字稿、中文旁白生成与试听、文字叠加、音视频合成、排序合并和项目保存恢复
- 重新生成语音、合成视频按原 Narration Studio 逻辑覆盖旧结果

## 录屏

1. 在主窗口切换到 **录屏**，选择 **应用窗口**、**浏览器页签**、**电脑桌面** 或 **框选区域**。
2. macOS 的应用、桌面和区域使用原生录屏：在当前工具内选择具体目标、帧率、画质、系统声音、麦克风、指针和点击效果。区域模式点击 **框选录制区域**，工具先隐藏，再在所选显示器的桌面上全屏框选，四角可调整；按 Enter 或 **确认录制区域** 返回设置，Esc 取消。**重新框选** 时取消会保留上次确认的范围。选择保存位置后倒计时 3 秒，开始录制时收起窗口，不跳浏览器。
3. **浏览器页签**保留 Chrome / Edge 的独立页签授权方式，需在所选浏览器中打开目标页签。其他系统使用浏览器兼容录制入口。
4. 可勾选 **录完直接进入视频制作**；从视频制作页点击“录屏”时默认启用，保存成功后自动导入。直接录制完成后也可点击 **添加旁白 / 编辑视频**。
5. 使用工具按钮或托盘菜单 **停止录屏并保存** 结束录制；可暂停后继续。停止快捷键为 `Ctrl/Cmd + Alt + Shift + R`。等待“已保存”后可打开所在文件夹。

Mac 原生录屏使用 ScreenCaptureKit / AVFoundation，需要 macOS 13+，首次允许 **ScreenShot** 录制屏幕。麦克风和点击效果需 macOS 15+，麦克风单独授权；系统声音与麦克风同时启用时会在保存阶段混合音轨。页签兼容录制使用新版 Chrome / Edge 的 `getDisplayMedia`，需要给所用浏览器授予屏幕录制权限，每次共享仍需用户选择授权；共享声音是否可用取决于浏览器、系统及来源。真实单页签采集与录制浏览器窗口是不同来源。

原生录屏直接写入本机临时 MP4，完成后提交到目标路径；截图工具自身的窗口会从桌面录制中排除。浏览器兼容录制分片写入本机文件，仅通过 `127.0.0.1` 连接 ScreenShot，不把整段视频积存在内存；页面需保留到保存完成。异常尽量保留带“未完成”的视频文件。正常退出工具会先停止录屏并保存。

原生录屏输出 MP4。浏览器兼容录制默认优先 MP4；选择 `.webm` 路径时优先 WebM，编码不可用时调整扩展名。实际路径显示在完成状态中。

## 视频制作与窗口布局

主窗口提供 **截图 / 录屏 / 视频制作**。截图与录屏保持紧凑窗口（初始 960 × 720）；首次进入视频制作最大化到可用桌面，也可手动切换系统全屏。两个工作区分别记忆尺寸、位置及最大化状态，切回时恢复；项目和编辑状态随工作区切换保留。

1. 点击 **视频制作**，录屏或导入已有视频；支持打开原 Narration Studio 保存的项目文件夹。
2. 给视频添加一个或多个时间范围，输入中文文字稿，选择语速，生成旁白并试听。
3. 默认 **Edge 中文女声（联网）**：文字稿会发送到在线语音服务。可切换 **本机语音（离线）**；Mac 使用 Tingting，Windows 使用系统语音。视频文件在本机处理。
4. 可插入文字、调整样式和显示时间，点击 **合成音视频**。旁白合成按原流程默认关闭原视频声音。
5. 重新生成语音和重新合成均覆盖同一旧结果；不会增加额外历史版本。按勾选顺序选择合成视频，可拖动排序、合并预览和导出。
6. **保存项目**将素材、文字稿、语音、合成视频及成片打包到项目文件夹。移动文件夹后可通过 **打开项目**继续编辑。

截图、录制与视频合成在本机执行；在线语音需要联网。打包包含媒体运行时，因此安装体积会增加；媒体进程在使用视频功能时才启动。来源及依赖说明见 [THIRD_PARTY.md](./THIRD_PARTY.md)。

## 添加文字

1. 框选后选择 **编辑截图**，在左侧工具栏选择 **文字**，点击截图中的位置。
2. 输入文字，按 `Enter` 换行；使用颜色选择器和字号滑块调整样式（12–96px）。
3. 点击 **添加文字** 确认，或按 `Esc` / 点击 **取消** 放弃当前输入。点击截图其他位置可继续添加，切换工具会确认当前文字。
4. 点击 **完成并复制** 或 **另存为**，文字会随截图一起导出；仍在输入中的文字也会自动确认。

输入框中的空格、换行和 `Ctrl/Cmd + Z` 保留正常的文字编辑行为。确认后的文字可与其他标注一起撤销/重做；文字超出截图边缘的部分会被裁切。

## 直接完成截图

1. 按 `Ctrl/Cmd + Shift + X` 冻结屏幕，拖动鼠标框选区域。需要微调时，拖动选框四角的小方块；拖动选框外的区域可重新框选。
2. 点击 **完成并复制**，或在未聚焦工具条按钮时按 `Enter`，直接复制选区原始像素并收起冻结窗口，可回到原来的应用粘贴。
3. 需要添加文字、箭头、马赛克等标注时，点击 **编辑截图**；需要拼接长图时，选择 **滚动长截图**。

直接复制不打开编辑器，也不执行用于编辑器预览的 PNG 编码。如果剪贴板写入失败，冻结窗口保留选区并显示错误，可重试复制或改为编辑截图。复制过程中会禁用重复提交和取消操作，避免重复写入。

调整角点时，对面的角保持固定，支持缩小、放大及越过对角点反向调整；范围限制在当前屏幕内。尺寸提示会实时更新，复制、编辑和滚动长截图均使用调整后的范围。

## 响应速度

- 启动时预先创建隐藏的框选窗口，后续截图复用窗口；取消或完成时清空画面和框选状态。
- Rust 缓存当前截图的原始像素。复制和保存只传递截图编号及标注，直接在后台合成并输出，避免整张图片反复进行 Base64 传输和 PNG 编解码。
- PNG 使用快速无损编码，导出的原始像素和透明度不变。减少冻结前的固定等待，在图片加载后立即显示覆盖层。
- 安装使用 Release 构建。Debug 构建的图像处理明显更慢，适合开发调试。

本机 2560×1440 合成图的单次处理基准：预览由旧 Debug 版约 1551ms 降至 Release 版约 98ms；截图 PNG 由约 2757ms 降至约 56ms。新复制路径不再进行整图 PNG 往返，带矩形标注的合成约 3ms。这些数值不包含屏幕捕获、窗口显示和系统剪贴板耗时，完整操作耗时取决于显示器及系统环境。

复现图像处理基准（不访问屏幕或剪贴板）：

```sh
cd src-tauri
cargo run --release --example latency
```

## 开发

```powershell
npm install
npm run media:install
npm run media:prepare
npm run tauri dev
```

只检查前端：

```powershell
npm run build
```

检查 Rust：

```powershell
cd src-tauri
cargo test
cargo check
```

录屏集成测试使用生成的画面和音频流，实际执行浏览器编码、区域裁剪、后台控制、分片保存、MP4 / WebM 解码和中断恢复，不访问桌面或麦克风。先安装 Playwright 及 Chromium，再运行：

```sh
cd src-tauri
cargo build --locked --example recording_harness
cd ..
npm install --no-save --package-lock=false playwright
npx playwright install chromium
node tests/recording.integration.mjs
```

已有 Playwright 时可用 `PLAYWRIGHT_MODULE` 指定模块路径，用 `RECORDING_CHROME_PATH` 指定 Chrome 可执行文件。自动化不替代系统共享选择器、屏幕权限和 Windows 实机验证。

视频制作集成测试使用生成的视频和本机语音，验证生成覆盖、文字合成、合并和项目迁移：

```sh
node tests/studio.integration.mjs
# 启动 Vite 后，使用已安装的 Playwright 验证同窗口工作区和录屏回填
node tests/studio.ui.mjs
# 桌面框选与录制范围回填，及旧录制结果不会误导入的回归（模拟 Tauri IPC）
node tests/recording-region.ui.mjs
node tests/recording-session.ui.mjs
```

macOS 原生编码器提供不访问屏幕/麦克风的自检：

```sh
src-tauri/resources/runtime/screenshot-recorder self-test /tmp/native-recorder-test.mp4
```

自动化覆盖合成媒体、模拟窗口 IPC 和真实编码器，系统共享权限、实际屏幕采集及 Windows 实机仍需人工验证。

## Windows 打包

```powershell
npm run tauri build -- --bundles nsis
```

生成产物：

- `src-tauri\target\release\screenshot-desktop.exe`
- `src-tauri\target\release\bundle\nsis\ScreenShot_0.1.0_x64-setup.exe`

说明：当前工程路径包含中文和 WPS 云盘目录，WiX MSI 打包可能报 `LGHT0001 / 0x8007007B`；NSIS 安装包已验证可生成。

## macOS 打包

```sh
npm run tauri build -- --bundles app
```

生成 `src-tauri/target/release/bundle/macos/ScreenShot.app`。复制到 `/Applications` 后启动；首次使用需授予屏幕录制权限。
